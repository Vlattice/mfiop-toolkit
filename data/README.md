# Data folder

Place reference PDB structures here before running the examples.

## Required for `examples/run_5SYF.py`

Download **PDB 5SYF** (αβ-tubulin, Alushin et al. 2014):

- Direct: https://files.rcsb.org/download/5SYF.pdb
- Structure page: https://www.rcsb.org/structure/5SYF

Place the file as `data/5SYF.pdb`.
